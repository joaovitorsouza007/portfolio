# Backlog


### Histórias de usuário - Autor


- US01 Como Autor, quero adicionar um novo projeto ao portfólio preenchendo um formulário simples com título, descrição, tecnologias, link do repositório, link da demo e imagem de capa, para que eu possa manter o site atualizado sem precisar mexer em código, e o projeto deve aparecer na página inicial após salvar sem exigir um novo deploy.
```Critério de aceitação:``` Sabendo que existem cards de projetos, quando o autor enviar um novo projeto, esse projeto deve ser exibido junto com os outros. O autor também deve conseguir editar, sendo visivel apenas para ele


- US02 Como Autor, quero ver métricas básicas de acesso ao site, como número de visitantes e quais projetos foram mais clicados, para que eu entenda o que está gerando interesse e possa melhorar minha vitrine continuamente.
```Critério de aceitação:``` Sabendo que usuarios vão acessar os projetos, o numero de visitantes deve aparecer, e os projetos mais vistos devem ficar em destaque.

- US03 Como Autor, quero fazer login no sistema com email e senha para acessar a área administrativa e gerenciar meus projetos, garantindo que apenas eu possa adicionar, editar ou remover conteúdo do portfólio.
```Critério de aceitação:``` Sabendo que o autor precisa gerenciar seu conteúdo de forma segura, ao acessar a página de login e inserir credenciais válidas, deve ser redirecionado para o dashboard administrativo onde poderá gerenciar seus projetos. O acesso ao dashboard deve ser restrito apenas a usuários autenticados.

- US04 Como autor, devo conseguir editar meus projetos cadastrados no sistema.
```Critério de aceitação:``` Sabendo que preciso alterar alguma informação, ao clicar no botão editar, devo conseguir mudar algum dado, arquivo ou foto etc e ele deve ser atualizado na interface.


### Histórias de usuário - Recrutador


- US05 Como Recrutador, quero poder conhecer melhor meu candidato para a vaga de emprego através do portfolio, quero ter acesso a informações como formação academica, conhecimentos e competencias, meus hobbyes e lazer.
```Critério de aceitação:``` Sabendo que o usuário possui qualificações e projetos, eles devem aparecer de forma clara e dinâmica.


- US06 Como Recrutador, quero baixar meu currículo em PDF diretamente do site com um único clique, para que eu possa anexar ao processo seletivo sem precisar solicitar ou buscar em outro lugar.
```Critério de aceitação:``` Sabendo que terá um botão de download para o curriculo, ao clica-lo, o curriculo deve ser baixado na máquina do usuário


### Histórias de usuário - Cliente


- US07 Como Cliente, quero visualizar comentários de outros clientes ou parceiros com nome, cargo e foto, para que eu me sinta seguro e confiante em contratar o autor para meu projeto.
```Critério de aceitação:``` Sabendo que pessoas vão escrever seus comentários, eles devem aparecer no site, e ficar visivel para o usuário


- US08 Como Cliente, quero ter contato fácil com o autor, conseguindo ver claramente suas redes como gmail, linkedin, whatsapp...
```Critério de aceitação:``` Sabendo que terão opções de contato, ao usuário clicar, ser redirecionado para os meios de contato.


### Histórias de usuário - Visitante


- US09 Como Visitante, quero que o site seja rápido e totalmente responsivo no celular e tablet, para que eu possa acessar e navegar confortavelmente de qualquer dispositivo e em qualquer lugar.
```Critério de aceitação:``` Sabendo que existem usuários em vários dispositivos diferentes, o site deve ser acessivel para todos


- US10 Como Visitante, quero comentar sobre os projetos numa aba de comentários
```Critério de aceitação:``` Sabendo que existe uma lista de comentários, quando um novo comentário for escrito, ele deve aparecer no começo dessa lista


- US11 Como Visitante, quero acessar o link dos projetos para poder testa-los
```Critério de aceitação:``` Sabendo que os links dos projetos vão estar logo abaixo, ao usuário clicar, deve ser redirecionado a outra página para ver o projeto
